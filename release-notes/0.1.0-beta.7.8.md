## Live TV and Sports

- Large guide imports now yield when playback starts or the app is close to its memory limit. Nuvio keeps the last completed listings available and retries the pending update automatically when playback stops and memory is available. On a first import, listings become available after that import finishes.
- Guide matching uses less memory when several playlists or channel variants share listings. The Home row also reuses its channel list when choosing which listings to load first.
- Opening Sports Hub now loads its saved schedule while a Live TV preview is active. If the shared schedule has never been cached, Sports can fetch it on opening. Bulk channel matching still waits for playback to finish.

## Stalker portal video on demand

- Movies and series from supported Stalker portals now appear in On Demand. Playback requests a stream link from the portal when you select a movie or episode, including compatibility handling for portals that refuse the initial request.
