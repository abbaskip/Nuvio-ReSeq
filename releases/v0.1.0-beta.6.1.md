# Nuvio ReSeq 0.1.0-beta.6.1

## Changes

- Fixes the missing left menu and Back exiting from Home/general navigation after full-screen Live TV or Sports playback. Full-screen state can now hide navigation only on the two playback screens, and Sports preview explicitly restores its non-full-screen state.
- Beta 6 has been withdrawn because of this navigation regression. This build installs over beta 5.4 or beta 6, preserving app data and the profile-local TMDB key.
- Includes beta 6's Sports preview/full-screen playback improvements, Stalker temporary-link and encoded-command fixes, and Advanced Discover with saved movie/TV searches. Personal TMDB keys remain encrypted on the TV and are excluded from APKs, backups and cloud sync.
- Adds regression coverage for a retained full-screen flag on Home and the other main screens; navigation tests now run in PR and release checks.

## Validation and limitations

- Full Debug suite: 2,933 tests, zero failures, two existing skips. All 38 release-tool tests pass.
- Signed release build, release vital lint and Play Store compilation pass. All five APKs have verified backend, tracker and Google Drive configuration, matching permanent signing and upgrade compatibility over beta 6.
- Onn 4K Pro: cold Home and the original retained-full-screen/warm-Home failure case both verified. Left opens the sidebar; after closing it, Back opens it again without exiting. A fresh pairing code was generated by the exact installed APK, and the original Android profile was restored.
- Some source feeds still interrupt; this release does not promise interruption-free playback on every source. Matching FHD and 4K comparison feeds also stalled in TiviMate. True 5.1 audio validation remains limited.
- The originally affected Stalker provider account remains unverified; protocol regression tests pass.
