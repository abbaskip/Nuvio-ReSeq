## CloudStream language and DNS controls

- Choose source languages on the Plugins screen. ReSeq filters each source inside an extension, including extensions that bundle several providers. Counts show the installed sources for each language.
- Select **All languages** to include every source. Sources with an unspecified or multilingual language remain available with any selection.
- Choose **CloudStream DNS** to cycle between the TV's system DNS, Cloudflare, Google and Quad9. DNS-over-HTTPS uses a separate resolver for CloudStream extension requests. Changes also reach extensions that retain a copy of the HTTP client.
- Language and DNS choices are saved per profile. Profiles that share the primary profile's plugins inherit these settings.
- Changing either setting starts a fresh stream search.

The initial settings are **All languages** and **TV system DNS**. Beta 8.3 also includes the extension settings and stream discovery fixes from beta 8.2.
