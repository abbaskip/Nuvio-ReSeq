# Nuvio ReSeq 0.1.0-beta.7.6

## Changes

- Load the existing ReSeq logo only when a web-configuration page requests it, avoiding eager resource reads when opening add-on, plugin, debrid and layout settings.
- Incorporates upstream Nuvio commit 2e05d6f with unchanged branding and web-server routes.

## Validation and limitations

- Full debug unit suite, APK build, Playstore compilation, complete lint regression guard and packaged-service checks are required before publication.
- Targeted logo tests cover exact bytes, stream closure and unavailable/unreadable resources. No device installation is required for this resource-loading change.
- Existing MDBList/TVDB identity and autoplay/source-tier changes remain held for design review.
