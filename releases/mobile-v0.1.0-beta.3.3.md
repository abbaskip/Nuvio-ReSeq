# Nuvio ReSeq Mobile Beta 3.3

In the Live TV guide, open **Search → Programmes** to find a show or movie by title. Tap an airing to see its programme actions, watch its channel or set a reminder. Channel search is still available.

In Sports Hub options, **Verify missing guide events** lets Gemini check unmatched IPTV listings against published schedules. It prioritises followed sports, checks up to four listings per request and links to the cited schedule. This is optional and requires a configured Gemini key.

To update from Mobile Beta 3.2, open **Settings → About and credits → Check for updates**, then tap **Download update**. The universal APK supports all packaged architectures. The smaller ARM64 APK is available for compatible devices.

ReSeq is an independent media player. Users supply their playback sources and are responsible for following provider terms, licensing requirements and applicable copyright law. The default Cinemeta and OpenSubtitles v3 endpoints provide metadata and subtitles. Third-party names identify compatibility and attribution. [Content sources and rights concerns](https://github.com/abbaskip/Nuvio-ReSeq#copyright-content-sources-and-independence)
