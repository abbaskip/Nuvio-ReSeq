# Nuvio ReSeq 0.1.0-beta.5.4

## Changes

- In Live TV, long-press a group and select **Manage visibility**. Tap OK to toggle a group's eye; hold OK again for **Hide all / Show all**. Press Back to save.
- Favorites, Recently watched and All channels can open visibility management. Built-in groups stay visible as a recovery route, with an emergency All channels row if all ordinary groups and optional built-ins have been hidden. Show all also restores hidden custom groups.
- Integrated 16 merged Nuvio upstream PRs since beta 5.3: retain the selected playback engine on retries, prepare debrid links off the main thread, restore Addons/Plugins focus, improve HLG/HDR and Cantonese subtitle detection, and update translations. Optional audio night mode and LFE downmix contribution default to off.
- Keep player source paging, addon selection and prepared links in one atomic state snapshot to avoid stale pages during background preparation.

## Validation and limitations

- Beta 5.4 signed release build and vital lint passed. All 249 targeted release tests passed with no skips or failures; all 31 release-tool tests passed.
- All five APKs have version code 10011, the existing release package and signing identity, matching application DEX payloads, complete native-library sets and correct ELF architectures. Signing and upgrade compatibility were checked against the published beta 5.3 APK. The actual APK DEX payloads were checked for the configured valid backend URL and API key; values are withheld.
- The upstream integration passed 2,869 Full Debug tests with two skipped and one confirmed configuration-dependent Trakt test excluded. Both distribution variants compiled and GitHub PR builds passed. The visibility change separately passed both compilation checks and all seven existing guide interaction tests.
- Existing Live TV redraw reductions, low-priority background work and the retained preview/fullscreen video surface remain in place. The hidden guide still runs beneath fullscreen playback; this release does not claim to eliminate every playback stutter or provider retry.
- Physical remote interaction, HDR output, passthrough and downmix listening have not been certified for this release. No sign-in readiness claim is made without an on-device QR/pairing check.
