# Nuvio ReSeq Mobile Beta 1.1

- Continue Watching keeps the selected episode order when you remove the last watch and refresh tracking. Saved cards can appear while the selected tracker loads after a restart.
- In airplane mode, open Home or Library to find downloads. Open a saved movie or episode for its title, synopsis and available artwork, or tap Play to start the local file. Opening older downloads online can fill in missing details.
- Downloaded files use a smaller read-ahead buffer in the built-in ExoPlayer. Mobile crash reports distinguish an Android low-memory exit from a Java exception and include the exception’s stack when available.
- The release includes Android Baseline and Startup Profiles for frequently used mobile screens, including Home, Details and the video player.

Install the arm64 APK on most recent phones and tablets. The universal APK supports the other Android architectures. Either APK updates earlier mobile builds and installs alongside ReSeq TV.
