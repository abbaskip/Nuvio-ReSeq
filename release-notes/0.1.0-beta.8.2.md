## CloudStream settings and stream discovery fixes

- Reach extension Settings directly with the TV remote, including from Test and the enable switch.
- Fix missing runtime libraries in release APKs that caused configurable extensions to fail.
- Use the catalogue title for CloudStream searches when IMDb-to-TMDB lookup is unavailable.
- Support extensions that look up installed companion packages.
- Correct the sample used to test TV-only providers.

Verified CineStream, ShowBox, StreamPlay and SuperStream settings with 93 providers installed. CineStream and Internet Archive played Big Buck Bunny in the release build. StreamPlay returned results, although sampled playback links stalled or returned HTTP 403. Ultima's separate bookmark integration remains unresolved.

This release includes the catalogue, About/update, Sports Hub and IPTV refresh improvements from beta 8 and beta 8.1.
