# Nuvio ReSeq 0.1.0-beta.7.2

## Changes

- Network settings correctly identify Wi-Fi or Ethernet when connected through a VPN.
- The fallback lookup runs only when the VPN does not report its underlying transport, and ignores networks without Internet capability.
- Incorporates the two upstream fixes from [Nuvio #4381](https://github.com/NuvioMedia/NuvioTV/pull/4381), with an additional regression covering non-VPN transports.

## Validation and limitations

- Full ReSeq unit regression suite, debug APK build, Playstore compilation, tooling tests and the shrinking released-source lint budget are required before publication. The signed release workflow verifies all five APK variants, packaged services and upgrade compatibility.
- Device interaction is not required for this informational network-classification change; remote/focus, playback, episode identity and persisted data paths are outside its code changes. No on-device test or sign-in readiness is claimed for this maintenance update.
