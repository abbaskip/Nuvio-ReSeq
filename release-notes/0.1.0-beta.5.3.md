# Nuvio ReSeq Beta 5.3

## Changes

- Improved IPTV On Demand episode matching for provider names containing the show title, release year, country tags and episode numbers. Names such as `Tulsa King (2022) - S01E01 - Go West, Old Man` now match the episode title correctly.
- When episode IDs and titles do not identify a source, use an explicit `SxxEyy` filename against Provider Default metadata numbers. Shuffled provider lists no longer make `S01E01` depend on its list position. TVDB orders use verified mappings to Provider Default, with conflicting IDs and multi-episode files kept out of this fallback.
- Added dedicated search from the On Demand page. Search the full imported libraries of enabled IPTV playlists, with a separate row per playlist, All / Movies / Series filters and more results loaded as you scroll.
- On Demand search respects hidden and locked groups and opens the provider's own details. Hidden copies are excluded before duplicate merging and paging, so they cannot crowd allowed titles out of the results.

Includes all fixes from Beta 5.2. Install over the existing app to retain your account, playlists and settings.

## Validation and limitations

- Regression coverage includes the reported Gilded Age and Tulsa King naming formats, alternate episode orders, playlist separation, filters, visibility, stale queries and paging beyond 300 results.
- Release APKs are checked for their package/version identity, compatibility with the existing release signing certificate and complete native libraries on every supported architecture.
- This revision has not been tested on the reporting user's TV or against their provider's live catalogue.
