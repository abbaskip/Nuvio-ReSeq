# Nuvio ReSeq 0.1.0-beta.7.1

## Tiered source autoplay

- **Immediate addon autoplay:** choose addons such as AIOStreams to start playback as soon as a playable result arrives. A 0.5-second pause lets the addon finish sending its ordered results. This tier uses the addon's own result order and bypasses normal autoplay filters.
- **Approved-source wait:** keep a separate selection of approved addons and sources for the normal autoplay timer. An addon may be selected for both tiers.
- **Any-source fallback:** optionally start any available playable source after a longer timeout. The source picker shows the remaining wait and offers Cancel autoplay. Fallback retains the existing source ordering and each addon's result order.
- Both timers start with the source search; the fallback must be longer than the approved-source wait. For example, 10/15 seconds leaves another 5 seconds in the picker. Fallback is off by default and is disabled when the approved wait is Unlimited.
- Manual selection, Cancel autoplay, and leaving the picker cancel pending automatic selection. Existing Reuse Last Link takes priority when enabled.
- Applies to initial playback, next episodes, in-player episode selection, and TV Mix continuation.

## TV Mix

- If no playable source is available at the longer fallback timeout, TV Mix tries another random show. Failed shows are excluded for that attempt without marking their episodes watched; a retry message appears if no shows remain.
- **Reorder Home Catalogs** can move or hide the TV Mix row across Classic, Modern, and Grid layouts. Ordering follows the existing per-profile settings, including addon-block ordering. Catalogue sync and addon-only web edits retain its saved position and visibility.

## Validation and limitations

The combined release is checked with focused autoplay, TV Mix, Home catalogue ordering/sync, and playback regression tests, Full Debug and Playstore Debug compilation, and the signed release pipeline. Finished APKs are checked for backend service configuration, upgrade signing compatibility, and native libraries. The preceding autoplay test build was installed over the existing Onn app with its account retained, and generated a fresh QR/pairing code in an isolated Android user. The final combined release has not had a full device playback acceptance pass. Real-provider timing, external-player completion reporting, and remote sync roundtrips remain dependent on configured providers and devices. TV Mix timeout recovery covers empty source searches; playback-engine or source-resolution failures after selection retain their existing handling.
