# Continue Watching background-work audit

The Onn capture on 11 November 2026 (16:53:31–16:55:41 Sydney) contained 269 metadata attempts across 267 distinct type/ID keys and 265 successful downloads. Most requests were different historical shows, not repeated attempts for the focused card. The installed build was 10046; these changes are not installed.

## Work removed or deferred

- Removed the independent history-wide badge metadata sweep. Badges use existing CW episode metadata and persisted state. Opening show details already evaluates that show's watched state.
- Persist the seed associated with a confirmed no-next-episode result in the primary CW path, and consult that result even when the in-memory resolution cache is empty after restart. Changed episode seeds and expired deadlines still require checking.
- Cached badge publication no longer extends metadata validation deadlines. Only actual resolution should refresh them.
- Older-show next-episode discovery waits for 30 seconds of an unchanged visible Home snapshot. It remains sequential and cancels when Home is hidden. This work remains necessary for automatic release alerts on older shows; it can still take time for a large, initially unvalidated history.
- Removed the Updating Continue Watching message and its state/translations.

## Work retained

- Recent Continue Watching resolution: at most 32 next-up candidates, four concurrent lookups, with cached/persisted results reused.
- Shuffle metadata: visible-Home lifecycle, at most 32 targets, two concurrent shuffle requests and shared metadata deduplication. Full episode lists are needed for a correct shuffle choice; images alone cannot replace them.
- Profile watch-history synchronisation and persisted cached cards, so already-known content can render before enrichment finishes.
- Sports guide cache streaming from build 10047 remains ready but untested on the device. Sports background matching supports followed fixtures/reminders; changing that behaviour needs separate evidence, rather than removing it as part of the CW badge audit.

## Validation boundary

The Home and watched-state regression suites passed: 139 tests, zero failures/errors. No new beta build, installation or publication was requested by this audit. Device memory/navigation testing remains outstanding when the Onn is available.
