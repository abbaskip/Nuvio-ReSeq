# Nuvio ReSeq 0.1.0-beta.9.6 — unpublished fix candidate

This artifact-only build has version code 10050. Beta 9.6 was withdrawn after an Onn memory-related ANR; beta 9.5 remains the latest public release. Publication remains on hold.

## Changes under device validation

- Remove On Demand from the sidebar. A shortcut at the top of Search opens the existing separate IPTV search; normal search results and matching are unchanged.
- Put the full library at Settings > IPTV > On Demand > Open IPTV On Demand library, with a resource-use warning recommending standard Nuvio Home. Back returns to Settings and releases the library screen model. Opening Settings only checks whether imported content exists; it does not open the library. Existing import and source-refresh behaviour is preserved.

- Move downloaded Sports feeds, schedules, tables and derived matching results into Android app cache, including existing files from older installs. Clearing cache preserves followed teams, favourites, settings and the small persistent AI request-budget ledger. Missing catalogue files force a full download instead of an unusable conditional response.

- Keep the shared Sports catalogue on disk and decode one league at a time. Build 10048 crashed while building its complete JSON tree on an OkHttp callback; a Perfetto heap graph also attributed about 62 MB to the retained provider payloads. Downloads now stream to a validated temporary file, preserve the last good cache, and keep only the catalogue header in memory.
- Start catalogue loading when Sports is first opened and cancel catalogue download/conversion when it closes. Refreshes remain conditional and six-hourly; live-score polling is separate and unchanged.

- Stream Sports guide cache reads and writes instead of holding a whole decompressed JSON string and document tree in memory. Reject stale keys before decoding events, share identical programmes across duplicate channels, and cancel interrupted cache work.

- Cancel Continue Watching and child metadata/badge jobs when Home is hidden or playback opens, and resume the latest snapshot when Home returns.
- Cancel shared addon metadata requests once their last caller leaves, while preserving a request still needed by another screen.
- Run Continue Watching calculations off the UI thread. Remove the separate history-wide badge download sweep; reuse persisted negative next-up results and defer older-show release discovery until Home settles.
- Pause Continue Watching work while Home is hidden; Sports opens immediately without a Continue Watching status message.
- Put cricket hero scores underneath each team, fit compact scores inside their rows, and leave unbatted sides blank.
- Match full cricket team names across providers so PAK/Pakistan and SL/Sri Lanka do not create duplicate cards.

## Validation

The Sports cache changes passed 209 local Sports tests and full CI regression/lint validation in the preceding candidate. The subsequent background-work audit and status-message removal passed 139 Home and watched-state tests. Shuffle selection behaviour is unchanged. Build 10048 passed full CI but failed Onn stress testing with an out-of-memory crash. This follow-up includes streaming, cache-reopen, malformed-feed and cancellation regressions. The memory/cache candidate 10049 passed an Onn navigation and heap-retention check. Build 10050 passed 127 targeted local tests, full CI regression/lint and APK verification, and an Onn navigation check covering separate IPTV search, the Settings library entry and warning, Back navigation, and populated Continue Watching on return to Home. See 0.1.0-beta.9.6-device-validation.md. Broader device stress testing is required before any publication; this candidate is not a confirmed complete memory fix.
