# Nuvio ReSeq 0.1.0-beta.9.6 — unpublished fix candidate

This artifact-only build has version code 10046. Beta 9.6 was withdrawn after an Onn memory-related ANR; beta 9.5 remains the latest public release. Publication remains on hold.

## Changes under device validation

- Cancel Continue Watching and child metadata/badge jobs when Home is hidden or playback opens, and resume the latest snapshot when Home returns.
- Cancel shared addon metadata requests once their last caller leaves, while preserving a request still needed by another screen.
- Run Continue Watching calculations off the UI thread and avoid launching one badge job per historical show.
- Display a non-blocking Updating Continue Watching message on Home.
- Put cricket hero scores underneath each team, fit compact scores inside their rows, and leave unbatted sides blank.
- Match full cricket team names across providers so PAK/Pakistan and SL/Sri Lanka do not create duplicate cards.

## Validation

All 377 targeted Home, metadata and Sports tests passed locally. The artifact workflow runs the full regression and lint gates. Device stress testing is required before any publication; this candidate is not a confirmed complete memory fix.
