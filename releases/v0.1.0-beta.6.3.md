# Nuvio ReSeq 0.1.0-beta.6.3

## Changes

- Advanced Discover is now above the main Search input. Text filters highlight during remote navigation; press OK to edit and open the keyboard, then Done or Back to return to the filter.
- Adds exact movie age-certification filtering for Australia, the US and the UK. The selected country/rating is retained in saved discoveries. TMDB does not provide the equivalent filter for TV discovery.
- Pins English, Spanish, French, German and Italian at the top of the language picker, separated from the remaining alphabetical list. Language search remains available.
- Clarifies that Advanced Discover uses the same profile-local TMDB API key field under Settings → Integrations → TMDB. No second personal-key field is required. Personal keys remain encrypted and excluded from APKs, backups and cloud sync.
- Removes repeated league labels from the Sports follow picker, preferring provider-backed entries such as NHL, NBA, WNBA, NFL, MLB and NRL. Existing saved league IDs remain resolvable.
- Continue Watching rebuilds on player exit even when the provider snapshot has not changed. Late startup cache reads no longer overwrite a fresher result; watched-history updates retain their full content rather than only the item count.
- Returning from the in-app player now requests an invalidated refresh through the existing connected-tracker coordinator for Trakt, Simkl and MDBList. One service failing does not prevent the others from refreshing. Nuvio uses the shared Continue Watching display/local-progress pipeline.
- On Demand stream matching looks up verified alternate/original series and movie names from an identified TMDB record, and TVDB series aliases where a TVDB series ID and access are available. This supports cases such as Gibi / As If without fuzzy title guessing. Year checks and rejection of conflicting TMDB/IMDb IDs remain in place.
- Retains the Stalker, Sports playback/navigation and result-date fixes from beta 6.2.
