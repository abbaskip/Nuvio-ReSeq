# Nuvio ReSeq 0.1.0-beta.7.7

## Changes

- Sports Hub's All Events feed opens at the first live event, with finished events available above it. Today's continuous list follows finished, live and upcoming order; events move automatically when their provider status changes, including while longer events remain live.
- Back from the Sports feed returns directly to its top menu. Left from the first menu button opens the Nuvio menu.
- Add IPTV favourite groups and playlist-specific group/channel ordering, including stable saved choices when adding another playlist.
- Reduce IPTV and On Demand storage use, improve language-aware VOD matching, and retain storage/import preferences and ordering together in backup and restore.
- Improve reused-link information and current-stream matching. Preferred plugin variants stay within enabled ReSeq source tiers, with complete fallback searches retained.
- Add Mark as Watched to Continue Watching while retaining TV Mix actions and verified split/combined episode handling. Improve MDBList anime episode mapping while preserving canonical TVDB identities and profile/account boundaries.
- Improve low-memory TV budgets, selected source-chip visibility, trailer Back behaviour, RTL slider/subtitle values, advanced-settings scrolling and saved Hide Unreleased Content settings.

## Validation and limitations

- Includes the combined source through `fe92fafa0` and the Sports changes accepted by the maintainer on the Onn's existing release-signed beta, with its app data retained.
- The combined base previously passed 3,212 JVM tests with two existing skips, 86 tooling tests, the complete lint regression guard, and 55 isolated TV fixtures. The final Sports behaviour was tested by the maintainer; the publication build does not rerun those test suites.
- All five release APKs use the permanent release signer and configured project services. Personal TMDB build credentials remain excluded. Existing ReSeq ART profile rules are retained; fresh profile collection and live-account tracker mutations are outside this update's verification.
