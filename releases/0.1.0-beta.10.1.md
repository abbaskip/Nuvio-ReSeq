# Nuvio ReSeq 0.1.0-beta.10.1

## Changes

- Make subtitle menus more efficient by reusing language lookups and unchanged option lists.
- Keep merged dialogue centered alongside left/right subtitle cues while preserving isolated or equally positioned cues.
- Recognize TorBox alternative-hash cached torrents; bound fallback checks to four concurrent requests. Existing source eligibility and Premiumize behavior remain unchanged.

## Validation and limitations

- Full JVM regressions, targeted subtitle/debrid fixtures, debug APK/service checks and the strict lint ratchet gate this update. No physical TV or live-account testing.
- Existing beta 10 behavior and update channel are retained. This release does not include the held upstream tracking/CW replacements.
