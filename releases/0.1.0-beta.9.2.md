# Nuvio ReSeq 0.1.0-beta.9.2

## Changes

- Continue Watching keeps shows visible while shuffle or TVDB metadata loads. A missing TVDB key opens the series for episode selection. The history window follows recent show activity across Nuvio, Trakt, Simkl and MDBList.
- Google Drive now syncs personal TVDB keys for matching profiles in a separate private file. Anyone with access to that file can read the keys. TMDB keys and tracker sessions stay on the device.
- Xtream Live TV groups follow the provider's category order unless you have customised their order.
- Usenet playback decodes articles in blocks and adapts read-ahead and seek handling to the connection. Sports Hub spends less time matching fixtures and continues to publish live score and channel updates as they arrive.
- Large stream lists use less main-thread time, and saving watch progress avoids repeated parsing.

## Validation

The full debug JVM suite passed 3,386 tests, with two live-service tests skipped. Thirteen Android TV emulator tests passed. NNTP and Sports measurements used local fixtures.
