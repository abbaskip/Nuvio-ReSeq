# Nuvio ReSeq 0.1.0-beta.9.6.1

Build **10051** replaces the withdrawn beta 9.6. This release contains the same application fixes as build 10050 tested on the Onn, with a higher version name and Android version code so existing beta 9.6 installations recognise it as an update. Install over your existing app to preserve settings and watch history.

## Changes

- Reduces memory pressure when opening Sports and On Demand by streaming Sports catalogue and guide-cache data instead of retaining complete JSON documents in memory.
- Pauses Continue Watching background work while Home is hidden, reduces unnecessary metadata work, and removes the lingering updating message. Shuffle selection behaviour is unchanged.
- Moves the full IPTV On Demand library from the sidebar to Settings > IPTV > On Demand > Open IPTV On Demand library, with a resource warning recommending Nuvio Home.
- Adds a shortcut at the top of Search to the existing separate IPTV search. Standard search results are unchanged.
- Stores downloaded and derived Sports files in Android app cache, so clearing cache frees space while retaining preferences, favourites and followed teams.
- Adds Cricket Australia as a secondary source for international cricket status, Sheffield Shield and One-Day Cup fixtures and scores.
- Keeps cricket live through drinks, lunch and tea, while using day status to distinguish overnight breaks from live play. International cricket and SportsDB BBL scores refresh every five minutes; Australian domestic scores refresh every fifteen minutes while Sports Hub is open.
- Adds international cricket country selections across Tests, ODIs and T20 internationals. Fits scores below their own team names, leaves unbatted sides blank, and reduces duplicate fixtures across providers.

## Validation and limitations

- Full regression and lint checks passed. All five signed APKs passed checksum, signing/upgrade identity, native-library, runtime and packaged-service checks.
- Build 10050 was installed on the Onn 4K Pro and checked through Home, separate IPTV search, the full library and return navigation, with no recorded crash or out-of-memory error during that pass. The preceding memory-fix candidate also passed Sports/cricket navigation and heap-retention checks.
- Cricket Australia availability and update timing depend on its website API. Provider HTTP 403 playback failures are not resolved by this update.
- The application fixes match tested source `98d71862c5ccb162347bdfaaa2a85e7a30c44e31`; this release changes the version identifiers and adds an updater regression check. Its signed release workflow repeats the full regression, lint and APK verification gates before publication.
