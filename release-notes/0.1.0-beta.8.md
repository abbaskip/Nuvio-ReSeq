## CloudStream

- Movie searches now include extensions such as Internet Archive and Dailymotion that use the general `Others` category. Refresh an existing CloudStream repository once to pick up the change.
- ReSeq searches all providers registered by an extension and loads resources supplied by the extension. Repository imports handle relative links and redirects, and a failed package update keeps the installed copy.

## Catalogues and collections

- Saved catalogue folders can recover when an add-on manifest finishes loading or a catalogue uses a different spelling of its content type. A failed first page shows an error, and a failed later page keeps the titles already loaded.
- Collection errors now distinguish a TMDB authorisation problem from an empty list.

## App updates

- In Settings → About, choose how often ReSeq checks for updates. You can still use **Check for updates** when automatic checks are set to **Never**.

## IPTV and Sports Hub

- **Update Playlists When Nuvio Opens** refreshes enabled playlists on launch and when you return to the app. You can change it in IPTV settings.
- Sports Hub’s channel picker now follows playlist changes across enabled sources. Event matching also updates when a provider changes a channel name without changing the number of channels.
