# Nuvio ReSeq 0.1.0-beta.9.6.2

## Changes

- Recognise encoded DASH MIME hints so compatible streams reach the DASH playback path.
- Use MPV's audio clock when a faulty video timestamp jumps back to zero outside a seek, preventing false Skip Intro prompts and seeks calculated from the wrong position.
- Make Home description auto-scroll follow a reading pace consistently across text sizes, preserving existing pauses and controls.

## Validation and limitations

The full host regression suite, complete lint budget, debug APKs and packaged project configuration are checked on the exact candidate before publication. The recovered rehearsal passed 3,498 JVM tests with two existing live-service skips and 104 tooling tests with one existing skip. Two resolved lint warning allowances were permanently retired. Native playback on physical devices was not tested. No physical devices or personal live accounts were accessed.

Existing episode identity, metadata and tracking rules, source tiers, IPTV/Sports/TV Mix features, profiles and saved settings remain preserved. Higher-risk route restoration, VOD HLS init repair and list-picker changes remain in their separate validation queue.
