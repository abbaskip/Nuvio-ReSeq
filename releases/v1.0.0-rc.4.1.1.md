# Nuvio ReSeq TV 1.0.0 RC4.1.1

## Updating on a TV with limited storage

- For future updates, ReSeq downloads the APK for the CPU architecture Android reports on your device. It falls back to the universal APK when a matching build is unavailable.
- Manual updates open the downloaded APK in Android’s installer. Android checks the package and signing identity. ReSeq no longer runs its own checksum or package compatibility check.
- In **IPTV storage and cleanup**, **Clean up unused data** now removes a pending update download, including one left by a failed install. If Android still has the installer open, close it and run cleanup again.
- When updating from RC4 or RC4.1, the older updater still requests the universal APK. If storage is tight, you can install the matching ARM APK from this release over your existing app. On those older builds, a pending download can also be reclaimed by running cleanup once it is 24 hours old.

## TV guide and catch-up

- **IPTV storage** shows the TV guide database and its SQLite journal on separate rows.
- Empty guide entries such as “No Program Guide Available” are omitted from saved listings. Guide maintenance also removes copies stored by earlier versions. The space recovered depends on what your guide provider supplied.
- On channels with catch-up, you can select an empty time slot to play from the archive. The guide splits gaps at hour boundaries and at the start or end of a real programme.
