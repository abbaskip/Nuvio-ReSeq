# Nuvio ReSeq 0.1.0-beta.7.3

## Sports Hub

- All Events now lists provider-backed sports fixtures in start-time order, with live status, results where available, and upcoming dates. EPG programme listings no longer qualify as events.
- TV Now is a separate tab for sports programmes currently airing in your configured TV guide.
- Event cards show their start times and open the existing details page for scores, channel suggestions and event information.
- Keep scheduled fixtures when a nearby guide airing exists, and remove TV Now entries when their programme ends.

## Validation and limitations

The development patch passed all 135 Sports unit tests. This release is checked against the current release source by the signed release pipeline, including Live TV, Sports, playback and updater regression tests, APK signing and upgrade compatibility, native libraries, and service configuration in the finished APKs. This update has not had an Onn device acceptance pass. Event scores and schedules depend on the sports data providers; TV Now and channel suggestions depend on your configured playlist and EPG. Existing date navigation and score-hiding preferences are retained.
