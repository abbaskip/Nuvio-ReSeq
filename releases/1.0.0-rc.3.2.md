# Nuvio ReSeq 1.0.0-rc.3.2

## Changes

- Honor saved Home hero sources before the first catalog load, avoiding a startup flash from an unselected source. Empty-selection defaults are unchanged.
- Mark Wi-Fi hardware optional for compatible Ethernet-only devices; existing Wi-Fi and network support remain available.

## Validation and limitations

- Gated by the full JVM regression suite, saved-hero/cancellation fixtures, debug APK/service checks, strict lint and the signed release workflow. No physical-device or live-account testing.
- Retains RC3.1 guide history, themes, Calendar and all shipped beta.3 adaptations.
