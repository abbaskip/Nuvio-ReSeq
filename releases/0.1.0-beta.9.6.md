# Nuvio ReSeq 0.1.0-beta.9.6

## Changes

- Reduces memory pressure while browsing On Demand by separating its layout settings from Home content processing and stopping Home shuffle jobs when Home is hidden.
- Improves Home navigation by avoiding episode-catalogue recalculation on focus changes and moving shuffle projection off the UI thread.
- Bounds shuffle metadata prefetch and reuses timezone data across each episode-catalogue scan.

- Adds Cricket Australia as a secondary source for international cricket status, Sheffield Shield and One-Day Cup fixtures and scores.
- Keeps cricket live through drinks, lunch and tea, while showing Stumps overnight instead of treating TV coverage as live play.
- Refreshes international cricket and SportsDB BBL scores every five minutes, and Australian domestic scores every fifteen minutes, while Sports Hub is open.
- Adds one international cricket country selection across Tests, ODIs and T20 internationals, with consistent My Sports rows and following.

## Validation and limitations

- All 94 targeted Home shuffle, selection and release-date tests pass, including regressions for lifecycle cancellation/restart, focus changes and a large metadata working set.
- The signed release workflow gates publication on complete regressions, lint, upgrade identity, native-library and packaged-service checks.
- All 206 Sports tests passed before release preparation; the final combined build is revalidated by CI.
- Cricket Australia coverage uses its website API and a bounded upcoming fixture window; availability and update timing depend on the provider.
- The source HTTP 403 failure is unresolved. These changes address the memory-heavy work identified in the two captured failures; device verification is still required.
