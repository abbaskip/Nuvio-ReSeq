# Nuvio ReSeq 0.1.0-beta.6

## Changes

- Sports Hub pauses background catalogue and channel-matching work during playback. Maximizing its preview keeps the existing video player and stream, including when the stream is paused or buffering.
- Select the Sports Hub preview with the remote and press OK for full screen. Right from All Events and Up from the My Sports featured game reach the preview. Back returns to Sports without briefly showing the EPG.
- Live TV rewind uses buffered recording, shorter rolling segments and a recorded startup lead. Cancelled recording sessions can no longer interfere with replacement sessions, and timestamp discontinuities no longer inflate rewind segments.
- Stalker playback honors static versus temporary-link flags, refreshes older cached imports, rejects incomplete playback URLs and retries compatible encoded channel commands.
- Advanced Discover adds movie and TV filters for genres, dates, language, ratings, vote counts and runtime, with sorting, saved searches and a hide-watched option.
- Set a personal TMDB API key in Settings → Integrations → TMDB to use Advanced Discover. The key is encrypted on the TV, scoped to the selected profile and excluded from backups and cloud sync; no personal key is bundled in the app.
- Release verification now checks the finished APKs for configured backend, Trakt, Simkl, MDBList and Google Drive integrations, alongside permanent signing, upgrade identity and native playback libraries.

## Validation and limitations

- All 2,930 Full Debug regression tests completed with zero failures and two existing skips. All 38 release-tool tests passed. Signed release and optimized test APK builds, Play Store compilation and release vital lint passed.
- All five release APKs use version code 10019, the existing production package and permanent signing identity, with complete native libraries and correct ELF architectures. Upgrade compatibility was checked against the published beta 5.4 APK. Finished APK DEX payloads were checked for the configured backend, all three trackers and Google Drive; personal TMDB build inputs were excluded.
- The signed release candidate was installed on an Onn 4K Pro and generated a fresh pairing code. Live movie and TV Discovery queries passed with a key entered at runtime by the owner, including genre selection, movie pagination to 40 results, opening title details and restoring focus on return. Saved-search creation, reopening, deletion and TV keyboard navigation were also checked.
- Sports playback and navigation have been exercised on an Onn 4K Pro, including preview/full-screen transitions and pause, resume and rewind. Some tested feeds still interrupted; this release does not promise interruption-free playback on every source. Matching FHD and 4K comparison feeds also stalled in TiviMate. True 5.1 audio coverage remains limited because several labelled feeds selected stereo.
- The Stalker regression tests cover the reported empty-stream response and cached-playlist migration. Playback against the originally affected provider account remains unverified.
