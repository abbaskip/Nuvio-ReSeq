## Playback settings

- Organize Stream Selection into Immediate, Timed autoplay, and Fallback. Allowed Add-ons sits directly below Autoplay from Add-ons.
- Set IPTV On Demand and Direct Usenet separately for each stage. Direct Usenet follows the Add-ons order by default, and saved stage-specific orders can be reset.

## Direct Usenet and IPTV On Demand

- Cap Direct Usenet releases by estimated average bitrate. Results with an unknown bitrate stay visible.
- Set the maximum release size and bitrate from the Usenet QR setup page.
- Customize stream names and descriptions for IPTV On Demand and Direct Usenet, using metadata from filenames, folders, and provider data when available.
