# Nuvio ReSeq 0.1.0-beta.9.1

## Changes

- Improve startup navigation by keeping catalog reads available during imports and moving guide observer work off the UI thread.
- Reduce repeated Sports Hub channel sorting allocations while preserving guide freshness and preference ordering.
- Speed up Usenet preparation and sequential reads with bounded article lookahead and automatic serial compatibility fallback.
- Resolve relative profile avatar URLs using the configured project backend.
- Adapt Trakt same-number episode handling for default metadata, preserving selected TVDB ordering.
- Apply the approved autoplay, Home and Details presets to fresh installations. Existing saved preferences retain their values.

## Validation and limitations

Combined local validation passed with 3,349 JVM tests, zero failures and two existing skips, plus 98 tooling and Sports feed tests. All five debug APKs built, Playstore Kotlin compiled, packaged-service checks passed and the lint guard passed. Local fixtures measured lower Sports merge allocations and faster Usenet reads. Overall TV heap retention and live provider performance still need manual confirmation. Physical devices and live accounts were excluded from automated testing.
