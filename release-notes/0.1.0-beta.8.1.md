## CloudStream extension settings

Beta 8 improved CloudStream repository imports, extension loading and stream discovery. Beta 8.1 lets you configure supported extensions directly on your TV.

- Open the Plugins screen and find an enabled CloudStream provider. If it offers configuration, select **Settings** beside **Test**. Use Back to return to that provider.
- ReSeq opens the extension's own settings screen. StreamPlay v694, CineStream v487 and SuperStream v38 were verified on Android TV.
