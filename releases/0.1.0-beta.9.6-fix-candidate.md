# Nuvio ReSeq 0.1.0-beta.9.6 — unpublished fix candidate

This artifact-only build has version code 10048. Beta 9.6 was withdrawn after an Onn memory-related ANR; beta 9.5 remains the latest public release. Publication remains on hold.

## Changes under device validation

- Stream Sports guide cache reads and writes instead of holding a whole decompressed JSON string and document tree in memory. Reject stale keys before decoding events, share identical programmes across duplicate channels, and cancel interrupted cache work.

- Cancel Continue Watching and child metadata/badge jobs when Home is hidden or playback opens, and resume the latest snapshot when Home returns.
- Cancel shared addon metadata requests once their last caller leaves, while preserving a request still needed by another screen.
- Run Continue Watching calculations off the UI thread. Remove the separate history-wide badge download sweep; reuse persisted negative next-up results and defer older-show release discovery until Home settles.
- Pause Continue Watching work while Home is hidden; Sports opens immediately without a Continue Watching status message.
- Put cricket hero scores underneath each team, fit compact scores inside their rows, and leave unbatted sides blank.
- Match full cricket team names across providers so PAK/Pakistan and SL/Sri Lanka do not create duplicate cards.

## Validation

The Sports cache changes passed 209 local Sports tests and full CI regression/lint validation in the preceding candidate. The subsequent background-work audit and status-message removal passed 139 Home and watched-state tests. Shuffle selection behaviour is unchanged. The artifact workflow runs the full regression and lint gates. Device stress testing is required before any publication; this candidate is not a confirmed complete memory fix.
