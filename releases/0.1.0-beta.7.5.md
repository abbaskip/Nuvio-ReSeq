# Nuvio ReSeq 0.1.0-beta.7.5 — urgent playback fix

## Changes

- Fix bursts of stuttering during regular movie and episode playback caused by optional background work competing for memory and CPU.
- Sports matching now stops when the player opens, including during large channel and guide searches. On Demand imports pause at safe checkpoints and resume after playback closes.
- Playback protection also covers pausing, buffering, seeking and overlapping next-episode sessions.
- Includes all changes from beta 7.4; no settings changes are needed.

## Validation and limitations

- Release gates cover player-session holds, worker resume, Sports cancellation and catalog-import safety, together with the existing release test suite. Signed APKs are checked for upgrade compatibility and packaged app-service configuration before publication.
- This addresses background resource contention; stream-provider or network interruptions can still occur. Extended Onn playback comparison remains pending.
